# AxiomIO is deprecated

AxiomIO was retired on August 26, 2026. Version `0.1.6` is its final legacy
release. This repository is retained as read-only historical source and will
not receive new features, provider integrations, compatibility updates, or
release builds.

Development has moved to [AxiomAI](https://github.com/astrea-foundation/axiomai).
The replacement combines AxiomCLI, its terminal interface, the secure inference
client and built-in local proxy, and the desktop application in one monorepo.
The replacement repository is private while the new product is under
development.

Internal development checkouts use:

```text
/home/salt/sync2/work/axiomai
```

Do not open feature work against AxiomIO or publish another AxiomIO release.
